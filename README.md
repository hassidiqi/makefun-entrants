# make.fun bounty entrants entry

Entry for [bounty-entrants-02](https://make.fun/bounty/bounty-entrants-02): "Get the most paying entrants across the bounties you launch on make.fun".

`BOUNTY.json` names the bounties this entry hands in. `main.ts` reads that file and prints each bounty's make.fun page, where a person can enter and pay the bounty's entry fee.

## Run

```sh
node main.ts
```

Node 22, standard library only, no network.
